# Vertex LMS v1.1 (Maintenance Release — CR1)

## Overview
Vertex LMS is a C++17 standalone, offline-capable Learning Management System built for High School Assignments and Assesments.

**Release v1.1** incorporates Change Request **CR1**:
- Class-wide assignment deadline extensions by lecturers.
- Automatic synchronization and display of extended deadlines on student assignment lists.
- Comprehensive regression testing suite.

## Quick Start (Windows Launcher)
Double-click `run.bat` to launch the interactive application or run the automated CR1 regression test suite.
